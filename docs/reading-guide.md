# 生物医学AI：先数据，再机制，再验证

核验截止：2026-10-02。本路线面向科研阅读，按数据背景、方法理解与证据审查逐步推进。基础概念见[综述](review.md)，公共来源与发表状态见[代表研究](representative-research.md)。

## 阶段一：认识实体、测量与独立样本

理解细胞、基因表达、scRNA/snRNA、批次、通路、Hi-C接触图、fMRI、抗体和抗原。画三张数据图：患者→细胞×基因；染色体→片段×片段；患者→脑区域×时间。标注测量单位、标签来源与独立性单位。

手算综述中的交叉熵、宏F1和阳性预测值例子，理解类别不平衡。读[U-Net](https://arxiv.org/abs/1505.04597)和[scGPT](https://www.nature.com/articles/s41592-024-02201-0)的摘要与结构图。遇到陌生名词，先判断它是生物实体、测量、先验还是预测标签。

阶段检查：能解释一万个来自同患者的细胞为何不能视为一万个独立患者；能说明随机细胞划分、新患者测试和新医院测试回答不同的泛化问题。

## 阶段二：精读三类代表机制

先读[scKAN](../papers/P354.md)的[正式论文](https://doi.org/10.1186/s13059-025-03779-0)第1—5页。画教师、学生、标签与无监督损失的关系，解释KAN曲线如何形成基因候选。记录药物案例获得的是预测、对接、分子动力学还是独立生物实验支持。核对标题、作者和DOI，避免与同名SCKAN混淆。

再读[HiCMamba](../papers/P344.md)的[正式论文](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1014057)第1、3—5页，画低覆盖输入、二维扫描模块与高覆盖目标。核对染色体窗口、降采样、细胞系及训练测试隔离。将像素相似、TAD、loop与表观验证分开理解。阶段检查：能解释图更清晰为何不足以证明恢复了真实结构。

最后读[scBIT](../papers/P345.md)的[作者稿](https://arxiv.org/abs/2502.02630)第1—5页及后续方法。画fMRI患者与snRNA患者两列，以相似性配对连接；不要假设两列是一一同人测量。明确推理时需要哪些输入，辅助模态来自何处，以及脑区域与基因子图关联能支持什么解释。正式日级出版日期仍需复核。

## 阶段三：围绕一个数据类型扩展阅读

单细胞线可读[scMCGraph](../papers/P361.md)与[scGSL](../papers/P360.md)，比较通路先验和图结构学习。影像线可读[MPCCI](../papers/P364.md)与[Better Eyes, Better Thoughts](../papers/P365.md)，分别审查因果识别假设与视觉感知条件。蛋白线可读[AbLWR](../papers/P366.md)，补充正例未标记学习、列表排序和新抗原外推。

[模糊真值校准](../papers/P060.md)提供标签歧义的另一视角。其医学分歧来自临床启发的合成标注，不能当作真实多医生重复标注。预测置信度要相对明确的标签定义评价。

每篇方法卡包含：科学问题、数据来源、独立单位、标签、模型、训练目标、划分、指标、解释证据与局限。未读正文的地方明确标注待核验，不从题名补写算法与结果。

## 阶段四：设计可靠性与解释性评价

选择一项失效风险，例如跨患者批次偏差、解释基因排名不稳定，或Hi-C稀有接触峰被平滑。固定数据划分，设独立队列，报告宏F1、稀有类拒识或结构恢复指标，同时衡量解释稳定性。

候选基因、药物与机制关联先保留候选措辞。原型、梯度、注意力和激活曲线可以说明模型依据，真实机制仍需独立实验。计算、体外、动物和临床证据按层级分别报告，不能由一种验证跳到另一种结论。

阶段检查：能写出假设、控制变量、基线、指标与失败判据；能指出评价设计中的泄漏风险；能说明什么证据会使自己的解释不成立。

## 阅读遇到困难时

不懂生物实体，先看测量定义与数据模式；不懂图，标出结点、边及来源；不懂损失，检查哪种错误预测会受惩罚；不懂解释，判断它指向模型决策还是现实机制；看不懂结果，先查划分单位，再看指标。

持续使用“论文事实、作者假设、待验证推测”三栏笔记。阅读的产出应是一张数据来源图、一份独立样本划分说明、一篇方法卡和一个有边界的研究问题，而不是未经验证的效果承诺。
